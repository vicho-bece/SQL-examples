---
EJEMPLOS DE BASE DE DATOS RELACIONALES
---

Este repositorio contiene diferentes proyectos con su propia temática sobre Base de Datos Relacionales.
Cada proyecto tiene por su contenido, un conjunto de datos iniciales, un archivo de instalación y uno o más archivo de consultas/funciones/administración.

Estos son los proyectos existentes según el sistema de gestión de Base de Datos:
1. PostgreSQL
  - [Tienda de Bicicletas](/Bike_store) 
2. MS SQL SERVER
  - [Tienda de Retail](/RetailShop)
